# Blackjack Academy Helper

A single-file blackjack training app: basic-strategy drills, Hi-Lo counting
practice, rule-aware strategy charts, a playable simulator, a course, a table
log and a session dashboard. No build step, no dependencies — open
`index.html` in a browser.

## Running it

```
open index.html          # or: npx serve .
```

All progress is kept in `localStorage` under the key `bjAcademyV3` and never
leaves the browser. The ⇅ button in the header exports everything to a JSON
file and imports it back — the way to move your progress to another device or
survive a cleared cache. The ↻ button clears it.

## What's in it

| Screen | What it does |
| --- | --- |
| **Train → Basic Strategy** | Deals real hands, grades against the current rule set, explains every miss and tracks your trouble hands. |
| **Train → Running Count** | Hi-Lo speed drill dealt from a real shoe, with adjustable rounds/cards/speed and a card-by-card review after each answer. |
| **Train → True Count** | Running count to true count, quizzing from decks remaining or from a discard tray, and showing the arithmetic. |
| **Train → Deviations** | Illustrious 18 + Fab 4 index plays, with the index and why it applied. |
| **Train → Simulation** | Playable 6-deck game: splits, doubles, insurance, surrender, 3:2 or 6:5, penetration and reshuffles, plus a coach that flags off-strategy plays and a hide-the-count self test. |
| **Charts** | Basic strategy for H17 / S17 / ENHC with DAS, surrender and peek toggles, generated by the same engine that grades the drills. Click any cell for the hand in full, what the code means, why the play wins, the index that changes it, and the measured expected value of every legal action — hit, stand, double, split, surrender — ranked best-first from a Monte Carlo run of that exact spot. A toggle outlines the cells the soft-17 rule changes. |
| **Course** | Fourteen lessons with completion tracking; each links into the drill that practises it. |
| **Assist** | Live hand helper: tap the dealer upcard and your cards and get the play instantly from the engine — with the index that changed it, the true count, insurance advice and your next bet. Jack, the built-in coach, explains it and answers questions in plain English. |
| **EV & Risk** | Monte Carlo analyzer. Describe the game and your bet spread; it deals millions of rounds in a Worker and measures EV/hour, standard deviation, risk of ruin, player advantage, N₀, the bankroll needed for a target risk, and the edge at every true count. |
| **Casinos** | Log the house rules of tables you play, get an estimated house edge for each — or measure the real one by simulation — and load any of them into the charts and trainer. |
| **Dashboard** | Session log across two bankrolls, computed metrics, bankroll curve and CSV export. The analyzer compares your logged results against the model and tells you how many standard deviations from expectation you are. |

House-edge figures are approximations for a basic-strategy player built from
commonly published rule-effect values; they describe the rules you enter, not
any particular casino's offering.

## Jack

Jack — short for blackjack — is the assistant built into the page. He parses
the question and answers from the same engine the charts use, so a play he
quotes is worked out rather than recalled: it matches the tables exactly and
follows whatever rules you have set.

He reads hands the way people actually write them — "my hand is an A and 3 and
the dealer shows a King" as readily as `16 v 10 at +2` — by finding and
removing the dealer phrase and then reading whatever ranks are left, rather
than demanding a fixed shape. He also does true-count arithmetic, seventeen
knowledge topics, and coaching from your own drill record. A count-driven play
gets the count's reasoning rather than the chart's, and half a hand gets a
question back instead of a refusal.

There is no model call, no key and no account, so he costs nothing and works
with the network off. The tradeoff is range: blackjack and this app are all he
knows, and he says so rather than bluffing.

## Tests

The strategy engine is what every other screen depends on, so it is covered by
an automated suite that drives the real page in Chromium:

```
npm ci                      # Playwright, the only dependency, and a test-time one
npx playwright install chromium
node tests/test-engine.mjs  # 67 strategy/index/shoe assertions
node tests/test-ui.mjs      # end-to-end pass over all seven screens
node tests/test-money.mjs   # 220 simulated hands reconciled against an
                            # independently computed settlement
node tests/test-sim.mjs     # 120M rounds checked against published figures
node tests/test-jack.mjs    # Jack's parsing, knowledge and engine agreement
```

`npm test` runs all five in order. They also run in CI on every push and
pull request — see `.github/workflows/tests.yml`, which installs Chromium
and runs each suite as its own step so a red build names the one that
broke.

`test-jack.mjs` checks the thing that matters most about Jack: for every one of
the 1,000 two-card hands against every upcard, the play he quotes is compared
against the engine's own answer. They agree on all of them. It also covers
twenty-six phrasings, all seventeen knowledge topics, that he follows the app's
current rule set rather than assuming one game, and that nothing reaches the
network.

`test-sim.mjs` is the one that decides whether the analyzer can be trusted. It
measures house edge per *initial* bet (the standard definition) and checks each
figure against published values within three standard errors of the
simulation's own sampling noise:

| | simulated | published |
| --- | --- | --- |
| 6D S17 DAS LS 3:2 house edge | 0.366% ±0.029 | ~0.36% |
| dealer hits soft 17 | +0.196 pp | +0.22 |
| no double after split | +0.136 pp | +0.14 |
| blackjack pays 6:5 | +1.359 pp | +1.39 |
| dealer busts | 29.58% | 29.76% |

It also checks the internal consistency that matters: flat-betting a 6D H17
game loses 0.562%, exactly the measured house edge for it, while the same game
with a 1-12 spread and the indices returns +0.708%.
